# Task Management System

A full-stack task management web application developed as a group project for **COSC 310: Software Engineering** at the University of British Columbia Okanagan.

The project focused on applying software engineering principles to the development of a functional web application, including collaborative development, database integration, software testing, and Agile project management.

## Tech Stack

- **Frontend & Backend:** Next.js, JavaScript
- **Database:** MongoDB Atlas
- **Testing:** Jest
- **Version Control:** Git & GitHub
- **Development Methodology:** Agile / Scrum

## Project Overview

The Task Management System was developed to provide a centralized application for organizing and managing tasks.

The project involved building a full-stack web application with a persistent database, connecting frontend components to backend functionality, and testing application behaviour.

Beyond the application itself, a major focus of the project was gaining practical experience working as part of a software development team.

## Development Process

The project was completed collaboratively as part of COSC 310, following an Agile development workflow.

Our team held regular Scrum meetings to discuss progress, plan upcoming work, and address technical challenges. Development tasks were distributed among team members, with Git and GitHub used to manage contributions and coordinate changes.

Throughout development, we worked on:

- Implementing and integrating application features
- Connecting application functionality to MongoDB
- Developing and testing components
- Debugging integration issues
- Collaborating through branches, commits, and pull requests

## Testing

Jest was used to develop and execute automated tests, helping verify application functionality and identify bugs during development.

## Project Background
